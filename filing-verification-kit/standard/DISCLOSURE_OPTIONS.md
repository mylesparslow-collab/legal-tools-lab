# Disclosure language options (DRAFT)

Status: every option below is a DRAFT that needs attorney approval. None has been reviewed or approved by an attorney. Personal portfolio demo. Not legal advice.

Why this page exists: see [bpc_6068_1_a3C] in `data/authorities.json`. The kit takes no position on what wording, placement or level of detail that provision calls for. Those points are in `OPEN_QUESTIONS.md`, question 3.

The General Counsel is asked to pick one option, edit it, or write a new one. The same text is kept in `data/disclosure_options.json`, which is what the checklist reads. Bracketed text is a placeholder; the checklist blocks a filing whose disclosure text still contains one.

## Option A: Short notice (DRAFT)

Status: DRAFT - needs attorney approval

> Generative artificial intelligence was used in preparing this document.

Shortest form. Says nothing about how the tool was used or what was checked.

## Option B: Notice with description of use (DRAFT)

Status: DRAFT - needs attorney approval

> Counsel used generative artificial intelligence to assist in preparing this document, specifically for [describe use]. Counsel reviewed all AI-assisted content.

Describes the use. The bracketed description must be filled in for each filing.

## Option C: Notice with verification statement (DRAFT)

Status: DRAFT - needs attorney approval

> Counsel used generative artificial intelligence to assist in preparing this document, specifically for [describe use]. The undersigned attorney personally verified every citation in this document and reviewed and corrected all AI-assisted content before filing.

Adds a factual statement about verification. Use only if the statement is true for the filing; the verification record should support it.

## Option D: Footnote form (DRAFT)

Status: DRAFT - needs attorney approval

> Disclosure of generative AI use: portions of this document were prepared with the assistance of generative artificial intelligence. The undersigned attorney reviewed the document in full and is responsible for its contents.

Written to sit in a footnote or after the signature block. Placement is a choice for the General Counsel; see OPEN_QUESTIONS.md.

## Choosing

- A shorter option says less that could later turn out to be inaccurate for a given filing.
- Options C and D make factual statements about what the attorney did. They should be used only when the verification record for that filing supports them.
- If a judge or court order on file requires specific text, that text is used in addition to, or instead of, these options. The judge-order lookup shows it.
- `custom` is accepted as an option id when the attorney writes filing-specific text.
